# Banking System

A comprehensive Java-based banking system with account management features.

## Features

- **Account Creation**: Create new bank accounts with account number and name
- **Deposit**: Add money to accounts
- **Withdraw**: Withdraw money with balance validation
- **Transfer**: Transfer money between accounts
- **Balance Check**: View current account balance
- **Transaction History**: View complete transaction history for each account

## Files

- `BankingSys.java` - Main banking system application
- `ArrayInsertion.java` - Array insertion algorithms
- `Arraylist.java` - ArrayList operations
- `Main.java` - Main class (possibly for testing)
- `MergedList.java` - List merging operations
- `TimeDifference.java` - Time calculation utilities
- `Zoo.java` - Zoo management system

## How to Run

1. Compile the Java files:
   ```bash
   javac BankingSys.java
   ```

2. Run the banking system:
   ```bash
   java BankingSys
   ```

## Menu Options

1. Create Account
2. Deposit
3. Withdraw
4. Check Balance
5. Show Transaction History
6. Transfer
7. Exit

## Usage Examples

- Create accounts with unique account numbers
- Deposit and withdraw money
- Transfer funds between accounts
- View transaction history for audit trails

## Error Handling

- Insufficient balance validation for withdrawals and transfers
- Account existence checks
- Input validation for all operations
